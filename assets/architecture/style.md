# 风格参考

每种风格只要抓住几个特征就能立住。**别混搭风格**——混搭是最难掌握的。

## 中世纪 / 乡村木屋

- 白墙（`white_terracotta` / 白色羊毛）+ **外露木框架**（`dark_oak_log` 横竖梁）
- 二层往外挑 1 格（"悬挑"），是这种风格最标志性的特征
- 陡坡屋顶（1:1 或更陡），深色木板
- 小窗、带木框、窗上可能有花箱
- 烟囱偏一侧，砖或圆石

## 现代别墅

- 白色/灰色混凝土，**大面积玻璃**
- 平顶或单坡，**没有出檐**（这跟别的风格相反）
- 体量是**几个方块错位堆叠**，不是一个大盒子
- 用横向线条（腰线、纱窗）分隔楼层
- 泳池、露台、大挑檐平台

## 日式

- 上白下木（或上木下白），**大屋顶、出檐很深**（挑 2 格）
- 屋顶坡度缓（比中式缓），深灰瓦
- 木格栅（`*_planks` 竖排）做墙面
- 架空的木platform（"缘侧"）+ 下面 1 格空间
- 庭院、石灯笼、竹

## 中式

- 白墙 + 深色木柱
- **屋顶是重点**：歇山/庑殿，出檐很深远，**屋脊两端上翘 1 格**
- 屋檐下有一圈斗拱（用楼梯块+半砖堆出层次）
- 对称、中轴、层层收进
- 红/金色只用在很小的构件上

## 欧式城堡

- 石砖为主，**转角塔楼**（圆形或方形，比主体高 3~5 格）
- 塔顶做锥形尖顶（越往上收越快）
- 城垛（每 2 格一个 1 格高的垛口）
- 门是拱形（用楼梯块拼圆弧）
- 窗深、小、带铁栅栏

## 沙漠建筑

- `sandstone` 系列，平顶或平缓单坡
- 厚墙（2 格）、小窗（为了遮阳，很合理）
- 平顶做女儿墙 + 屋顶露台
- 木料少用，用 `acacia_log` 做点缀

## 雪地 / 北欧

- `spruce_planks`（深木色）+ 石基
- **非常陡**的屋顶（1:2，为了让雪滑落）
- 屋顶上可以铺一层雪（`snow_block`）
- 窗户小而暖色（用发光方块做灯）

## 挑风格的实用建议

- **第一次搭就选中世纪木屋或乡村风**：容错高，材料简单，容易出效果。
- 想显得"有设计感"：现代别墅其实最难（要控制体量关系），不建议新手。
- 中式/日式的关键是**屋顶**，屋顶做对了就成功一半。

## 一句话特征（应急用）

| 风格 | 一句话 |
|---|---|
| 中世纪 | 白墙黑木架 + 陡屋顶 + 二层悬挑 |
| 现代 | 灰白 + 大玻璃 + 平顶 + 体量错位 |
| 日式 | 大出檐缓坡顶 + 木格栅 + 架空平台 |
| 中式 | 深远出檐 + 翘起的屋脊 + 对称 |
| 城堡 | 石墙 + 角楼 + 城垛 + 拱门 |
| 沙漠 | 沙岩 + 厚墙 + 小窗 + 平顶 |
| 北欧 | 深木 + 极陡屋顶 + 积雪 |
