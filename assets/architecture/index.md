# 建筑美学数据集 · 总目录

给搭房子用的一套经验规则。**先读这一页，再按需要读具体主题。**

## 用法

开工前先读 `index`（这页）。动手前至少读 `proportion` 和 `mistakes`。
搭屋顶前读 `roof`；砌墙开窗前读 `wall`；挑材料前读 `color`。

| topic | 内容 |
|---|---|
| `proportion` | 比例与体量：层高、开间、长宽比、退台 |
| `roof` | 屋顶：形式、坡度、出檐、压顶 |
| `wall` | 墙体与开窗：分层、窗台、墙垛、转角 |
| `color` | 配色与材质：三色原则、明暗、常见搭配 |
| `parts` | 常见构件：门廊、台阶、栏杆、烟囱、阳台 |
| `mistakes` | 避坑清单与自检表 |
| `style` | 风格参考：中世纪、现代、日式、中式、城堡 |

## 搭房子的标准流程

1. **先定体量**：长、宽、高各多少格。想象成一个盒子，盒子不对后面全白搭。
2. **铺地基**：比建筑外轮廓**多出 1 格**（做裙边/台阶），y=0 那一层。
3. **砌四壁**：先做四面完整的墙（别急着开窗），确认比例舒服。
4. **开窗开门**：按开间节奏来，别随手挖洞。
5. **收顶**：屋顶外挑 1~2 格，坡度优先 1:1（45°）。
6. **加细节**：转角立柱、窗台、屋檐支撑、勒脚。
7. **最后配色**：主色铺大面积，辅色做对比，点缀色只用在很小的构件上。

## 三条最容易被忽略的硬规则

- **屋顶一定比墙深色**，地基一定比墙深色。头重脚轻会立刻显假。
- **窗户不要满墙**。留出至少 1 格宽的墙垛，墙面才有节奏。
- **别只搭外壳**。建筑至少 3 格高时，里面要有地板和夹层，否则从上面看是个空盒子。

## 坐标约定

- `y=0` 是最底层，`y` 向上增加。
- 尺寸 `X × Y × Z`，其中 **Y 是高度**。
- 放方块用基岩版 id，例如 `minecraft:stone`、`minecraft:oak_planks`。
- 楼梯块（`*_stairs`）和半砖（`*_slab`）是做细节的主力，别只会用整块。
